# Support

ProxyManager is maintained as an open-source project without a service-level agreement.

- Use GitHub Issues for reproducible bugs and focused feature requests.
- Use private vulnerability reporting for security issues.
- Include the ProxyManager version, Windows build, sing-box version, rule shape, and redacted runtime messages.
- Do not post proxy passwords, access tokens, customer data, or private configuration files.

Questions about sing-box itself belong in the upstream sing-box support channels. Questions about a commercial proxy provider belong with that provider.
