# UI 重做计划 — IntentRoute AI

## 问题诊断

当前 UI（v0.17）存在以下核心问题：

1. **色彩对比度不足**：背景 #0B0E14、表面 #10141B、卡片 #151A23 差异极小，在普通显示器上几乎看不出层次
2. **页面结构单一**：8 个页面全部是一个大灰色卡片填满内容区，内部没有分组
3. **缺乏视觉焦点**：数据密集的列表页面缺乏视觉焦点，难以快速定位关键信息
4. **操作反馈弱**：按钮点击后没有明确反馈，批量操作没有进度提示
5. **页面缺乏主题色**：没有利用 Accent/Success/Warning/Error 色彩来区分不同功能区

## 设计方案

### 一、重新设计色彩系统

| 元素 | 当前值 | 新值 | 说明 |
|------|--------|------|------|
| 背景 | #0B0E14 | #0D1117 | 略微提亮，减少"深渊感" |
| 表面 | #10141B | #161B22 | 提亮到 GitHub Dark 水平 |
| 卡片 | #151A23 | #1C2128 | 提亮，增加与表面的对比 |
| 边框 | #272E3A | #30363D | 略提亮，边框更清晰 |
| 文字主色 | #E6EDF3 | #E6EDF3 | 保持不变 |
| 文字次色 | #9AA5B4 | #8B949E | 略微调暗，增加对比 |
| 文字弱化 | #5F6B7A | #484F58 | 更明显弱化 |

### 二、引入"主题色分区"概念

每个页面顶部添加一个带主题色的渐变条或卡片头，让用户一眼区分当前在哪：

| 页面 | 主题色 |
|------|--------|
| 规则管理 | Accent #4C8DFF |
| AI 策略体检 | Success #3FB950 |
| AI 路由推演 | Warning #D29922 |
| AI 规则助手 | Accent #4C8DFF |
| 运行日志 | Muted #5F6B7A |
| 进程列表 | Warning #D29922 |
| 设置 | Accent #4C8DFF |
| 关于 | Muted #5F6B7A |

### 三、页面内容重设计

#### 3.1 规则管理页
- **卡片化操作区**：搜索框 + 统计徽章 + 操作按钮分组
- **数据卡片**：每条规则一个卡片，左侧是状态圆点+名称，右侧是模式标签+操作
- **空状态**：大图标+引导文字+快速操作按钮

#### 3.2 AI 规则助手页
- **三栏布局**：左侧意图输入+生成，中间草稿预览，右侧校验结果
- **状态卡片**：生成进度、校验结果、已添加统计

#### 3.3 AI 策略体检页
- **仪表盘风格**：顶部大数字 KPI 卡（活跃规则数、警告数、严重问题数）
- **发现列表**：每条发现用卡片展示，带严重度标签
- **解释面板**：底部独立卡片

#### 3.4 AI 路由推演页
- **表单卡片**：输入区域（进程名、目标地址、端口、协议）+ 推演按钮
- **结果卡片**：大图标 + 动作文字 + 匹配规则信息
- **轨迹列表**：展开式/卡片式

#### 3.5 运行日志页
- **终端风格**：深色背景 + 代码字体 + 行高适中
- **过滤工具栏**：搜索框 + 级别下拉 + 自动滚动开关 + 导出按钮
- **日志条目**：每行时间戳（灰色）+ 内容，错误行高亮

#### 3.6 进程列表页
- **卡片式列表**：每进程一个卡片，显示 PID、名称、路径、状态
- **操作按钮**：添加规则、刷新、搜索

#### 3.7 设置页
- **分区卡片**：每个设置组一个独立卡片
- **表单式布局**：标签 + 输入控件，每个设置项独占一行

### 四、新增组件

1. **主题色渐变条**：每页面顶部的装饰性渐变（Accent → Transparent）
2. **状态徽章**：带颜色的小标签（如"已启用"绿色、"已禁用"灰色）
3. **统计卡片**：数字 + 标签 + 趋势指示
4. **空状态组件**：大图标 + 引导文字 + 操作按钮

### 五、保持不变的部分

- 窗口大小和位置
- 侧栏导航结构和页面切换逻辑
- 本地化字符串引用
- 无障碍自动化 ID（冒烟测试依赖）
- 所有事件处理器签名和数据绑定

- 本地 318 测试全部通过

## 风险控制

- **UIA 自动化 ID 保持不变**：所有 x:Name 和 AutomationProperties.AutomationId 不动
- **事件处理器签名不变**：所有 Click/Changed 事件处理器保持原样
- **本地化字符串不变**：所有 loc:Strings 引用保持原样
- **冒烟测试兼容**：NavRules → 空格键切换逻辑不变
- **分步提交**：每阶段一个独立 commit，便于回滚
